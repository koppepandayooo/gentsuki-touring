# 原付ツーリング

原付向けのルート検索・ナビをするスマホ用Webアプリ（PWA）。

## できること
- 場所検索（Photon / 国土地理院 / Nominatim。見つからなければ「旧」などを外して再検索）、地図の長押しで地点指定・マイスポット保存、経由地
- 原付で入れない目的地（歩行者用トンネルなど）は手前の道まで案内し、残りの徒歩距離を表示
- 現在地の誤差が500m以上（パソコンなど）のときは現在地を出発地に使わない
- 表示テーマ: 自動 / ライト / ダーク（夜用は紺グレー系）
- 原付ルート検索（Valhalla `motor_scooter`）: 高速・自動車専用道路を通らない。速度設定（一種30km/h）で所要時間を計算。代替ルートも表示
- **二段階右折の可能性**: 片側3車線以上の道路からの右折を地図に「二段階」マーク（車線数は OpenStreetMap 由来なので目安）
- **二段階右折を避ける**: まず普通のルートを出し、裏で「大通りを避けた案」「二段階右折の右折先をふさいだ案」を探して、少ないルートが見つかれば差し替える（1回あたり2分相当として所要時間と比較）
- **ストリートビュー**: 曲がり角一覧の📷・二段階マーク・規制区間・長押しメニューから、進む向きでGoogleマップのストリートビューを開く（APIキー不要）
- **二輪通行規制区間**: 日本二輪車普及安全協会の全国データを地図に表示。ルートが通る場合は警告し、自動で回避して再検索
  - 時間帯規制（22:00〜翌6:00 など）は今の時刻で判定
  - 地下道・陸橋の規制は、ルートが横の側道を通っていれば「付近」扱い
- **曲がる回数**: 設定で「少なめ」「なるべく直進」を選ぶと、曲がる回数の少ないルートを優先（1回あたり1分/3分相当として比較）。ルートごとに曲がる回数を表示
- 住所検索は「〜番」までしか位置が分からないので、入力した住所はそのまま表示し、ピンをドラッグして細かく直せる
- **スマホに送る**（パソコンのみ）: 出発地・経由地・目的地・設定を URL に入れて QR コードで渡す。アカウント・サーバー不要。スマホは同じ条件でルートを出し直す
- ナビ（スマホ・タブレットのみ。パソコンではルートを調べるだけ）: 出発地を入力したときはそのルートのまま案内し、ルートに乗るまでは「出発地点まで」の表示で待つ。進行方向が上になる地図、次の曲がり角・距離、日本語音声案内、ルート外れで自動再検索、速度表示（一種は30km/h超で赤）、画面スリープ防止

## 構成
- `web/` … アプリ本体（静的ファイルだけ。サーバー不要）
- `web/data/regulations.json` … 規制区間データ
- `web/data/road-names.json` … 道路の正式名 → 通称（例: 八王子五日市線 → 秋川街道）の手動の表。これに無い「〜線」は、地図データの alt_name を Nominatim で自動で調べて端末に保存する。長押しメニューから自分で呼び名を付けることもできる（優先順: 自分で付けた名前 > この表 > 自動）
- `tools/scrape_jmpsa.py` … 規制区間データの取得（JMPSAは毎年6月更新なので、その後に再実行）

```
python tools/scrape_jmpsa.py
```

## ローカルで動かす
```
python -m http.server 8810 --directory web
```
公開版: https://koppepandayooo.github.io/gentsuki-touring/ （main に push すると GitHub Actions で web/ が自動公開される）

## 使っている無料サービス
- ルート: valhalla1.openstreetmap.de（FOSSGIS の公開サーバー。個人利用の範囲で）
- 検索: photon.komoot.io / 国土地理院 住所検索 / Nominatim（逆ジオコーディング）
- 地図: OpenFreeMap（OpenStreetMap のベクトル地図、MapLibre GL で表示。日本語表示・店アイコンと3D建物は非表示。ダークモードは dark スタイル）
- 規制区間: 一般社団法人日本二輪車普及安全協会 二輪車通行規制区間情報
